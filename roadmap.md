- [x] Substituir o formato resumido por uma aula guiada completa em todos os cursos
- [x] Criar conteúdo específico por matéria, linguagem e tipo de atividade
- [x] Melhorar leitura, hierarquia visual, exemplos e explicações no celular e computador
- [x] Oferecer prática adequada a cada assunto: código, visualização ou análise guiada
- [x] Tornar vídeos, tutor, revisão, quiz e progresso parte coerente da aula
- [x] Auditar todas as lições para eliminar a antiga divisão entre aula completa e resumo
- [x] Testar cursos representativos de todas as áreas em celular e computador
- [x] Índice clicável, controles de leitura, checkpoints com dicas progressivas e versão para PDF

- [x] Prova final + projeto final + certificado por curso
